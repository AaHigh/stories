The High Tower District September 30

A day late

Happy Birthday, Craig.

For Craig Smith, who co-wrote the construction set for Ultimate Wizard while we were teenagers. September 30. Posted the morning after.

Craig,

Yesterday was your birthday. I am a day late, which is a better average than some of the lava trolls we shipped.

We wrote that construction set in our houses in North Richland Hills. Sean Moore and Steve Luedders had already built Wizard for Progressive Peripherals. We called them, learned the memory layout, and built a set that could do what the original one only hinted at. Treasure matrices. The special effects that were already in the main levels. The first set still had pieces of those features in the code, turned off.

Progressive took what we wrote and sold it as the Wizard Expansion Set. Electronic Arts, Paul Reiche III included, used that same set to build new levels, then put the set in the box. Ultimate Wizard, 1986. One hundred levels, and a construction set with our names on it.

We were teenagers. The box still looks like we meant it.

Happy birthday.

Aaron

What the page says

The Wikipedia article is filed under Wizard, the 1984 game. Ultimate Wizard gets its own section. This is the part about us, in their words.

Craig Smith and Aaron Hightower teamed up to make an improved construction set in their homes in North Richland Hills, Texas. They communicated with Sean and Steve to understand the memory layout for the levels and then set out to create an advanced construction set better than the one included with the original game.

Progressive Peripherals released that code as the Wizard Expansion Set, with 50 contest levels. Those contest levels could not use the new features, because they had been built in the old set. Electronic Arts used our set to make a new run of levels, kept a mix of the old screens and the expansion screens, turned the difficulty up on some of them, and changed a few monster sprites. The construction set shipped in the box.

Compute!'s Gazette, December 1986, liked the "instant playability," and said Ultimate Wizard had become a favorite of the neighborhood youngsters. Fair. We were the neighborhood youngsters.

Press fire when ready.

Happy birthday, Craig. A day late, from the other name on the construction set. The levels are still in there if you want them.
